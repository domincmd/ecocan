Como Operamos

Nosso projeto é dividido em duas grandes partes: a lixeira inteligente e o servidor. Cada uma desempenha um papel essencial para que tudo funcione de forma automatizada e organizada.


Lixeira

Na parte física, desenvolvemos um sistema composto por três elementos principais: um Arduino, um sensor ultrassônico e um servo motor. O sensor e o servo são acoplados a um cano, enquanto o Arduino fica fixado na estrutura (como dá para ver na foto, que explica mais do que mil palavras).

A dinâmica é a seguinte: quando uma latinha é inserida, ela desce pelo cano e fica temporariamente segurada por um chão retrátil acionado pelo servo motor. Assim que a latinha é detectada pelo sensor ultrassônico, essa informação é enviada para o Arduino. O Arduino, então, libera o chão retrátil para que a latinha caia no compartimento e, ao mesmo tempo, envia um código para o servidor — é aqui que a parte digital começa.


Servidor

A segunda parte é um pouco mais sofisticada. Nosso servidor, que também hospeda o website, é responsável pela lógica do sistema. Apesar de conter várias camadas técnicas, podemos simplificar o funcionamento.

Ao acessar o site, o usuário vê uma tela com duas opções: criar uma conta ou entrar com uma conta existente. Depois de logado, ele é direcionado para a página inicial, onde pode realizar diversas ações:


  • Reivindicar pontos, inserindo o código gerado automaticamente pela lixeira ao reciclar.
  • Trocar recompensas, utilizando os pontos acumulados.
  • Acessar páginas de informação, como esta em que você está agora.
  • Sair da conta, voltando para a tela inicial.

Sempre que o servidor recebe um código enviado pelo Arduino, esse código é armazenado na base de dados. Dessa forma, o usuário pode inserir esse código manualmente para resgatar seus pontos — é quase como um sistema de “cupom de reciclagem”.

Além disso, quando alguém troca seus pontos por uma recompensa, essa ação é registrada e vai para um painel administrativo, onde os responsáveis podem verificar a solicitação, entregar o item físico e marcar a operação como concluída.
