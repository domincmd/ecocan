Detalhes técnicos

Código

Na parte do código, nosso projeto é totalmente open-source. Todo o desenvolvimento pode ser acessado publicamente e redistribuído livremente, desde que os devidos créditos sejam mantidos. Acreditamos que compartilhamento de conhecimento impulsiona projetos melhores, então deixamos tudo documentado e disponível para quem quiser estudar, adaptar ou contribuir. O repositório completo está no link abaixo:

https://github.com/domincmd/ecocan

Software:

Nosso site foi desenvolvido em NodeJS, utilizando os módulos Express (responsável pela parte de servidor e rotas do site) e SerialReader (que faz a comunicação direta com o Arduino para leitura dos dados). A base de dados foi construída com LowDB, que armazena as informações em um arquivo .json, garantindo simplicidade e agilidade no desenvolvimento.

A interface web foi feita com HTML e CSS padrão, mantendo leveza e compatibilidade com qualquer navegador. Em algumas páginas foi utilizado EJS para permitir a renderização dinâmica de dados diretamente no frontend.

Hardware

No hardware, utilizamos um Arduino Uno como unidade de controle principal, acompanhado de um servo motor (modelo específico definido no protótipo final) para o mecanismo de abertura e um sensor ultrassônico HC-SR04, responsável por detectar a aproximação da lata. Essa combinação permite uma automação simples, eficiente e de baixo custo, ideal para um projeto educativo e replicável.
